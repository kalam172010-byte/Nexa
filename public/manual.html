2 System Overview & Core Capabilities

The Kalam FF Panel is an enterprise software platform designed for automated digital key generation, inventory stocking, multi-tier duration distribution, and payment collection.

Core Capability Pillars
The platform eliminates manual operations. When a user deposits funds via UPI or purchases a digital key, the wallet credit and key delivery occur instantly without requiring administrator intervention.
Module Primary Functionality Underlying Technology
Authentication Password login, Google OAuth, and 6-digit email OTP Firebase Auth + JWT Tokens
Digital Inventory Multi-duration keys (1H, 3H, 1D, 7D, 30D) with auto-stocking Firestore + JSON Data Engine
Automated Payment Dynamic UPI QR codes, instant confirmation FamGateway UPI API Adapter
Reseller Outbound Third-party bot integration & upstream sync HMAC API Master Keys
Administration 14-tab system control center with custom live branding Role-Based Admin Console

3 Complete Operating Workflows

A. Automated UPI Deposit Flow

[User selects Game & Duration] (e.g. Free Fire V5 Bala Mod - 1 Day) │ ▼ [Balance Verification] ├─ If Balance < Price ──► Prompt for Deposit └─ If Balance >= Price ──► Proceed to Allocation │ ▼ [Wallet Balance Deducted] ──► Atomic Transaction │ ▼ [Key Allocation from Active Stock] ──► Marked Assigned to User ID │ ▼ [Instant Key Modal Displayed] ──► Shows Key, Copy Button & Mod APK Download

C. Outbound Reseller API Flow

[External Telegram Bot / Website] │ ▼ [HTTP POST /api/reseller/buy with x-api-key] │ ▼ [Balance & Parameter Verification: product_id & duration] │ ▼ [Digital Key allocated & JSON response delivered in < 150ms]
